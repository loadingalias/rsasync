# rsnetwork-udp

**DO NOT USE IN PRODUCTION.**

rsnetwork-udp sends and receives datagrams on a UDP socket that the caller owns, with segmentation
offload, ECN, packet information, and truncation. It also holds the system declarations that the
networking family and its runtimes share.

rsnetwork-udp is in development. Each release can change the API.

rsnetwork-udp is a crate of [rsasync](https://github.com/loadingalias/rsasync).
