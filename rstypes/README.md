# rstypes

**DO NOT USE IN PRODUCTION.**

rstypes holds the types that rsasync shares with networking and applications: owned buffers,
capacity, and time. It has no scheduler and no driver. An application uses these types through
rsasync.

rstypes is in development. Each release can change the API.

rstypes is a crate of [rsasync](https://github.com/loadingalias/rsasync).
